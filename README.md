🚫 Скрыватель блока с друзьями

Это расширение скрывает блок с друзьями на страницах профиля в социальных сетях VK.ru и OK.ru.

❗️ Важно: сейчас расширение доступно только через ручной способ установки (ниже). Как только я добавлю его в Chrome Web Store — вы сможете просто нажать «Установить».

🛠 Установка вручную
Скачайте архив
Нажмите здесь или скачайте последнюю версию из раздела Releases на моей странице GitHub.
Распакуйте архив
Найдите скачанный файл hidefriends.zip и распакуйте его куда-нибудь на диск.
Откройте настройки расширений
В браузере Google Chrome откройте страницу по адресу chrome://extensions.
Включите режим разработчика
Справа вверху страницы есть переключатель «Режим разработчика». Перетащите его вправо, чтобы он стал синим.
Загрузите расширение
Под этим переключателем нажмите кнопку «Загрузить распакованное».
Выберите папку, которую вы распаковали ранее (например, C:\Users\ИмяПользователя\Downloads\hidefriends).

Готово! Расширение установлено.

✅ Теперь при открытии страниц профиля на VK.ru и OK.ru блок с друзьями будет скрыт.

💡 Совет: Чтобы не потерять расширение после обновления браузера, можно сохранить папку с файлами где-то ещё (на диске D:, в облаке или на флешке), а потом заново загрузить её в браузер по инструкции выше.
