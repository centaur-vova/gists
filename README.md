# 🚫 Интерфейс — это трение

Это расширение убирает лишнее из интерфейса VK.ru. Лучший интерфейс — его отсутствие.

### Что оно делает?

- Скрывает левую колонку (друзья, подписки).
- Убирает верхнюю панель с меню и счетчиками уведомлений.
- Избавляет от рекламы на странице профиля.

> Я не пытаюсь улучшить дизайн. Я просто уменьшаю трения между мыслью и действием.

### 📌 Установка вручную

1. Скачайте архив здесь или замените ссылку на свою.
2. Распакуйте файл `hidefriends.zip` куда-нибудь на диск.
3. В браузере Google Chrome откройте страницу по адресу: `chrome://extensions`.
4. Включите режим разработчика (*переключатель справа вверху*).
5. Нажмите кнопку *«Загрузить распакованное»*.
6. Выберите папку, которую вы распаковали ранее *(например, C:\Users\ИмяПользователя\Downloads\hidefriends)*.
7. ✅ Готово! Расширение установлено.

**Совет:** Чтобы не потерять расширение после обновления браузера, сохраните папку с файлами где-то ещё (на диске D:, в облаке). При необходимости её всегда можно заново загрузить через инструкцию выше.
