# 🚫 Скрыватель друзей

Это расширение скрывает блок с друзьями на страницах профиля в социальных сетях VK.ru и OK.ru. Также оно убирает красный счётчик уведомлений (сообщения/заявки) в верхней панели VK.ru.

> ❗️ Важно: пока что это расширение доступно только через ручной способ установки. Как только я добавлю его в Chrome Web Store — вы сможете просто нажать «Установить».

## 🛠 Установка вручную

1. ### Скачайте архив

   - Нажмите здесь, чтобы скачать последнюю версию (*или замените ссылку на свою*).

2. ### Распакуйте архив

   - Найдите скачанный файл `hidefriends.zip` и распакуйте его куда-нибудь на диск.

3. ### Откройте настройки расширений

   - В браузере Google Chrome откройте страницу по адресу `chrome://extensions`.

4. ### Включите режим разработчика

   - Справа вверху страницы есть переключатель **«Режим разработчика»**. Перетащите его вправо, чтобы он стал синим.

5. ### Загрузите расширение

   - Под этим переключателем нажмите кнопку **«Загрузить распакованное»**.  
   - Выберите папку, которую вы распаковали ранее *(например, C:\Users\ИмяПользователя\Downloads\hidefriends)*.

6. ✅ Готово! Расширение установлено.

Теперь при открытии страниц профиля на **VK.ru** и **OK.ru** блок с друзьями будет скрыт, а в VK.ru исчезнет красный счётчик уведомлений.

### 💡 Совет:

Чтобы не потерять расширение после обновления браузера или переустановки системы, можно сохранить папку с файлами где-то ещё (на диске D:, в облаке или на флешке). При необходимости её всегда можно заново загрузить в браузер по инструкции выше.
